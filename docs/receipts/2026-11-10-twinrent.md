# TwinRent local planner

Date: 2026-11-10

TwinRent replaces the M8 stub. The checklist stays in `.jewbot/twinrent-plan.json` and records only step ids and statuses. Publish cannot be marked done. `health()` calls `probeOllama` (`GET /api/tags`) after `assertLocalSpendOnly`. `twinrent_draft` calls `chatOnce` after the same gate, on local Ollama at `http://127.0.0.1:11434`. Credentials, keystrokes, emails, and phone numbers do not fetch. Nothing is published.

`npm run test:twinrent` mocks `fetch`. It does not start Ollama and it does not call a rental platform.
