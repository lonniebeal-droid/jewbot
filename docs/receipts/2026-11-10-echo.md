# Echo local worker

Date: 2026-11-10

Echo replaces the M8 stub. The module talks only to local Ollama at `http://127.0.0.1:11434` with model `tinyllama`. `health()` calls `probeOllama` (`GET /api/tags`) after `assertLocalSpendOnly`. `echo_task` calls `chatOnce` after the same gate. Paid hosts, LAN hosts, credential requests, and keystroke requests do not fetch.

`npm run test:echo` mocks `fetch`. It does not start Ollama and it does not call a paid API.
